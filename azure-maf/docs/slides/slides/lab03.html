Lab 03 · O primeiro acesso ao sistema

A description é o contrato

@tool(
name="consultar_status_rede",
description="Retorna a situação de um CEP.
Use sempre que o cliente relatar lentidão...",
)

Troque por “Consulta coisas” e ele erra a hora.

A description não é documentação para humano: é o único material que o modelo tem para decidir se chama a tool, e quando. Faça a troca ao vivo — é a demo mais barata e mais convincente do lab, porque nenhuma linha de código muda. Quando a tool de vocês não é chamada, o problema quase nunca está no código dela.
