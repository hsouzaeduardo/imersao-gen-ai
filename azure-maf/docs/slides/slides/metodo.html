Cada lab existe porque o anterior falhou de um jeito específico.

Não vamos construir o agente certo de primeira. Vamos construir o errado, seis vezes, e deixar cada falha escolher a peça seguinte. Se a turma levar só esta frase, a aula já valeu: arquitetura de agente não é catálogo de recursos, é uma sequência de problemas.
