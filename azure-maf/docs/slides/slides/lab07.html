Lab 07 · O agente que não é seu

A mesma linha, outro dono

remoto = A2AAgent(url="http://...:9000")
 
Agent(cliente, INSTRUCTION, tools=[
remoto.as_tool(name="consultar_tecnico"),
])

MCP padronizou o dado. A2A padroniza o agente.

A linha do as_tool é idêntica à do lab 05, byte a byte. O que mudou foi onde o especialista mora, e o maestro não tem como saber. É o mesmo movimento do lab 04, um nível acima: lá o agente parou de falar com o banco e passou a falar com um servidor MCP; aqui parou de importar o especialista e passa a falar com um endpoint A2A. Rode --card antes do código: o agent card é o contrato, e tem o mesmo formato da description de uma tool. Depois derrube o servidor do outro time: agora o especialista é dependência de rede, com timeout, versão e alguém de plantão que não é você.
