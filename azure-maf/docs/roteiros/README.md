# Roteiros, um por lab

Um arquivo por lab, para você abrir **só o do lab que está dando**. Cada um é
autocontido: preparação, partes com o comando e a fala, edições ao vivo com o
desfazer, perguntas que a turma faz, o que fazer se der errado, e o gancho para
o lab seguinte.

| Lab | Tempo | Precisa no ar | Roteiro |
|---|---|---|---|
| 01 · Primeiro dia, sem crachá | 45 min | só o modelo | [lab01.md](lab01.md) |
| 02a · O caderno de anotações | 50 min | Redis (opcional) | [lab02a.md](lab02a.md) |
| 02b · O prontuário do cliente | 50 min | só o modelo | [lab02b.md](lab02b.md) |
| 03 · O primeiro acesso ao sistema | 60 min | API de rede | [lab03.md](lab03.md) |
| 04 · A chave do banco de dados | 80 min | Toolbox + API | [lab04.md](lab04.md) |
| 05 · Promovido a líder de equipe | 60 min | Toolbox + API | [lab05.md](lab05.md) |
| 06 · O processo operacional | 70 min | Toolbox + API | [lab06.md](lab06.md) |
| 07 · O agente que não é seu | 45 min | dois terminais | [lab07.md](lab07.md) |
| 08 · A prova de que funciona | 80 min | Toolbox + API | [lab08.md](lab08.md) |

## O que NÃO está aqui

O material transversal fica em [`../CONDUCAO_LAB_A_LAB.md`](../CONDUCAO_LAB_A_LAB.md):

- **o elenco da base** — quem é cada CPF, e qual persona serve a qual demo
- **o ritmo** — quanto cada comando demora
- **a cola de uma página** — para ficar ao lado do teclado
- **os erros comuns** — a tabela de sintoma e causa

E o operacional puro, sem didática, em [`../COMO_EXECUTAR.md`](../COMO_EXECUTAR.md).

## A corrente das falhas

Cada roteiro termina com o gancho do próximo. Lida de ponta a ponta, é a história
do curso:

```
01  esquece o CPF do turno anterior
02a a sessão morre com o processo
02b lembra de tudo, e não sabe de nada
03  e a minha fatura de agosto?
04  um agente, três assuntos, nenhuma especialidade
05  a ordem varia: roteamento por LLM é probabilístico
06  todos os agentes são seus
07  "funcionou na demo" não é evidência
08  —
```
